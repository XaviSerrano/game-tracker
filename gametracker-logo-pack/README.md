# Gamepad logo pack

## Files
- `logo-principal.svg`: full-color main logo.
- `isotipo.svg`: controller symbol without wordmark.
- `favicon.svg`, `favicon-16.svg`, `favicon-32.svg`: simplified icon for browser/app use.
- `monocromatico-fondo-oscuro.svg`: light mark for dark backgrounds.
- `monocromatico-fondo-claro.svg`: dark mark for light backgrounds.

All assets are SVG vector files and can be scaled without pixelation. The favicon SVGs use the same scalable geometry; when exporting raster favicons, export at 16×16 and 32×32 px respectively.

## HTML usage
```html
<img src="/assets/logo-principal.svg" alt="Logo" />
<link rel="icon" type="image/svg+xml" href="/assets/favicon.svg" />
```

## Notes
This is an original controller-inspired mark, not an official Nintendo/GameCube logo or product asset.
