# GameTracker — Brand colors

| Token | HEX | Use |
|---|---|---|
| Background / Ink | `#0B0D10` | Primary dark surfaces |
| Surface | `#15191F` | Cards and elevated surfaces |
| Surface Soft | `#202630` | Borders and secondary surfaces |
| Text / White | `#FFFFFF` | Primary logo on dark backgrounds |
| Text Muted | `#A7B0BC` | Secondary text |
| Accent Green | `#4FF739` | Small highlights and active states |
| Accent Green Dark | `#349B26` | Hover / pressed accent |

Recommended usage: use the white mark on dark backgrounds for the primary identity. Use the dark mark on light backgrounds. Reserve green for accents rather than recoloring every brand element.
